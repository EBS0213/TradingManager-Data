# TradingManager Data

TradingManager에 과거 리포트와 컨퍼런스콜을 추가하는 선택 설치 확장팩입니다. 프로그램은 먼저 [TradingManager](https://github.com/EBS0213/TradingManager)에서 설치하세요.

## 다운로드

[최신 데이터 릴리스](https://github.com/EBS0213/TradingManager-Data/releases/latest)에서 **TradingManager-Research-2026.11.08.zip**과 SHA-256 파일을 받으세요. GitHub가 자동으로 표시하는 **Source code** 압축파일에는 데이터가 없습니다.

2026-11-08판은 맥미니의 17:00 KST 보관 시점과 기존 GitHub 게시 원본을 기준으로 합니다. 리포트 게시물 243개·PDF 249개, 컨퍼런스콜 1,704건을 포함합니다. 콜은 새 파이프라인 1,601건과 구형 103건입니다. 회사·작성일이 같아도 다른 PDF 판본은 보관했습니다. 작성일은 PDF 파일명과 게시물에, 발표일은 콜 항목에 있습니다. GitHub 보관 PDF의 등록일은 파일명의 문서 작성일로 복원했습니다.

스크리너 자료는 포함하지 않습니다. 프로그램의 로컬 스크리너가 처음 시작할 때 수집하고 이후 예약 또는 수동 실행합니다. 스크리너가 없는 확장팩을 설치해도 리포트·콜 조회에는 문제가 없습니다.

## 설치

1. 본 프로그램 설치를 완료하고 한 번 실행합니다. 로컬 DB가 켜져 있어야 합니다.
2. 데이터 ZIP을 전부 압축 해제합니다. 기존 프로그램 폴더를 덮어쓰지 마세요.
3. macOS는 `Install-macOS.command`, Windows는 `Install-Windows.cmd`를 실행하고 **기존 TradingManager 프로그램 폴더** 경로를 입력합니다.
4. 앱의 리포트·컨퍼런스콜 화면을 새로고침합니다.

macOS에서 내려받은 실행 파일을 보안 설정이 막으면 압축을 푼 폴더에서 터미널로 아래 명령을 실행할 수 있습니다. Node.js 22 이상과 본 프로그램에 설치된 `pg` 의존성을 사용합니다.

```sh
node --max-old-space-size=4096 restore.mjs "/설치한/TradingManager" --check
node --max-old-space-size=4096 restore.mjs "/설치한/TradingManager"
```

`--check`는 전체 데이터 무결성과 대상 설정을 확인하며 DB를 변경하지 않습니다. 복원은 이 컴퓨터의 PostgreSQL에만 연결합니다. 계정·인증키·개인 기록·스크리너 결과를 옮기지 않습니다. 프로그램 소스와 기존 설정을 유지합니다.

## 기존 자료가 있는 경우

같은 PDF 해시나 같은 종목·분기의 콜이 있으면 기존 내용을 유지합니다. 적용 이력을 기록하므로 재실행 시 중복 등록하거나 설치 후 삭제한 자료를 다시 살리지 않습니다. 새 자료 등록은 하나의 트랜잭션으로 처리하며 오류가 나면 되돌립니다.

맥미니 DB의 수치/주석 길이 제한으로 잘렸던 콜은 같은 원문 해시의 게시 원본으로 복원해 담았습니다. 이미 설치된 콜은 덮어쓰지 않으므로 그 설치에 남아 있는 잘린 값은 자동 보정하지 않습니다.

## 범위와 검증

파일 크기·SHA-256·PDF 해시와 콜 원문/번역의 원문 해시 연결을 검사합니다. 새 임시 DB에서 전체 복원, 재실행, 기존 수정·삭제 보존을 검증합니다. 모든 보고서의 분석 정확도나 번역의 문장별 품질을 보증하는 것은 아닙니다. 데이터팩 버전과 프로그램 버전은 별도로 관리합니다.

자료별 권리와 출처 안내는 [DATA-NOTICE.txt](DATA-NOTICE.txt)를 확인하세요.
